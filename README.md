# lstm-predictor
"LSTM Stock &amp; Crypto Predictor"

Overview of this Project:
The model developed is founded on Long ShortTerm Memory (LSTM) on memory architecture. Prior to the
training phase, the data underwent comprehensive preprocessing,
normalization, and exploratory data analysis (EDA). When assessed using Google stock data, the model achieved a remarkable
variance regression score of 0.96, reflecting its high predictive
accuracy. This proposed approach aims to refine the development
of objective data-driven tools that support investors in making
well-informed decisions regarding their investments.

Index Terms—Stock Market, LSTM, Deep Learning, Regression, Forecasting, Asset
